# Parcial 3 · PROG3 — Parte práctica (60 %)

**UTEC · Programación III · Ciclo 02-2026**
Arreglos unidimensionales y colecciones · Inventario de «DistriSalva, S.A. de C.V.»

Trabaje en el navegador con **GitHub Codespaces**: no necesita instalar nada.

## 1. Abrir el entorno

1. Inicie sesión en GitHub.
2. En esta página pulse el botón verde **Code** → pestaña **Codespaces** →
   **Create codespace on main**.
3. Espere 1–2 minutos. Se abre VS Code en el navegador con el archivo
   `Parcial3ArreglosColecciones.java`.

> No necesita copiar ni hacer *fork* del repositorio. Sus cambios quedan en su
> propio Codespace y nadie más los ve.

## 2. Resolver

- Complete los **5 métodos** donde dice `COMPLETAR (TODO)`, en orden.
- Lea las **PISTAS** del comentario de cada método antes de escribir código.
- Borre la línea `throw new UnsupportedOperationException("TODO ...")` de cada
  método que complete.
- No cambie el nombre de la clase, del archivo ni las firmas de los métodos.

## 3. Probar (en la Terminal, abajo; si no la ve: menú ☰ → Terminal → New Terminal)

Prueba rápida con el `main()` de la plantilla:

```bash
bash probar.sh
```

Verificador con las pruebas públicas:

```bash
bash verificar.sh
```

Corrija hasta ver **«Puntaje: 20 de 20»**. Pasar las pruebas públicas no
garantiza el 10: la calificación incluye además casos reservados.

## 4. Entregar en Moodle

1. En el panel izquierdo (Explorador), clic derecho sobre
   `Parcial3ArreglosColecciones.java` → **Download**.
2. Suba **únicamente** ese archivo en la tarea **«Parcial 3 — Ejercicio
   práctico»** de Moodle antes de la hora límite.

No suba la carpeta `marco` ni el archivo de pruebas.

## Al terminar

Cierre la pestaña. Si quiere liberar su cuota de Codespaces:
<https://github.com/codespaces> → `⋯` junto a su codespace → **Delete**
(hágalo **después** de entregar en Moodle).
